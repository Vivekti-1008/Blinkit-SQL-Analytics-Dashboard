# 🛒 Blinkit SQL Analytics Dashboard

## 📌 Project Overview
This project is a Blinkit-inspired analytics dashboard built using **MySQL, Python, Streamlit, Faker, Pandas, and Plotly**.

The project simulates a real-world e-commerce grocery platform with over:

- 100,000 Orders
- 300,000+ Order Items
- 10,000 Customers
- 1,000 Products

It includes advanced SQL analytics and an interactive Streamlit dashboard for business insights.

---

## 🚀 Features

- KPI Cards for Orders, Revenue, Customers
- Revenue by City Analysis
- Payment Method Distribution
- Top Selling Products
- Realistic Synthetic Data Generation
- Interactive Dashboard using Streamlit

---

## 🛠️ Tech Stack

- Python
- MySQL
- Streamlit
- Faker
- Pandas
- Plotly

---

## 📊 SQL Concepts Used

- Joins
- Group By
- Aggregation
- Sorting
- Revenue Analytics
- Customer Analytics
- Product Analytics
